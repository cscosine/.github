# Rules

[cscosine-rules.md](cscosine-rules.md): the rules of every cscosine repository, for people and agents. It is the
section "cscosine rules" of each repository's `CLAUDE.md`, copied as is; the rest of that file is what is specific to
the repository.

Until the project template exists (`plans/PLAN-cscosine-org.md`, S3), the section is copied by hand into a
repository's `CLAUDE.md` when the repository is next touched; then the template owns it and `copier update` keeps it
in sync.
